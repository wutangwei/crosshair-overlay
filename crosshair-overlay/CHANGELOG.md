# Changelog

## v1.0.0

首个公开版本。

### 功能
- 8 种准心样式：十字、圆点、圆环、T 形、X 形、人字、方框、三角
- 7 种预设色 + 自定义取色
- 尺寸 / 线宽 / 间隙 / 不透明度独立可调
- 位置精度 0.1 px，支持微调与一键归中
- 深色 / 浅色主题，3 种强调色，带淡入淡出切换
- 面板可收起为小胶囊
- 全局热键 `Ctrl + Alt + H` 显示 / 隐藏
- 配置自动保存

### 修复
- **浅色主题圆角出现黑点**：colorkey 无法处理半透明像素，抗锯齿边缘与近黑色键混合后
  产生的颜色既非面板色也不等于键色，无法被裁掉。改为面板背景**硬边渲染**（alpha 仅 0/255）。
- **拖动不跟手 / 坐标翻倍**：Tk 在 150% 缩放下 `geometry()` 会做二次换算，
  且操作的是 `TkChild` 而非 `TkTopLevel`。改为直接对顶层窗口 `SetWindowPos`。
- **隐藏后 2 秒自动重现**：`_position()` 里多余的 `SWP_SHOWWINDOW` 把隐藏窗口又显示了。
- **热键失效**：热键事件被丢进了面板自己消费的命令队列，改为独立的事件队列。
- **不透明度滑块失灵**：重构为局部刷新后，`-alpha` 只在 `build()` 里设置。
- **淡入淡出卡顿**：大尺寸背景图在高倍超采样下生成过慢，改为大面积图用 2× 超采样，
  并在切换前预热图片。
